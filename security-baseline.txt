# Accepted dependency advisories — security baseline
#
# Every ID below was reviewed against THIS application's actual code paths and judged
# unreachable or not materially exposed. CI compares the live pip-audit result against
# this file and fails on anything NOT listed, so a new advisory cannot slip in silently.
#
# Re-review this file at every release. Format: one advisory ID per line.
#
# -------------------------------------------------------------------------------------
# pillow (all IDs) — NOT REACHABLE
#   pillow is a transitive dependency of streamlit. This application never imports PIL
#   and never calls Image.open(); verified with `grep -rn "PIL\|Image.open" app/ ui/`
#   returning no matches. The decoder CVEs require decoding an attacker-supplied image.
#   Ceiling: streamlit 1.41.1 pins pillow<12, so the fix needs a streamlit major upgrade.
#
# starlette (all IDs) — NOT REACHABLE / LOW
#   - Range-header ReDoS and Windows UNC SSRF both require StaticFiles or FileResponse.
#     This app mounts neither; verified with `grep -rn "StaticFiles\|FileResponse\|mount("`
#     returning no matches.
#   - Host-header path injection requires logic that reads the reconstructed request.url.
#     Nothing in app/api does; verified by grep.
#   - urlencoded form-limit bypass: the two upload routes use multipart, every body is
#     validated by Pydantic, and the server binds 127.0.0.1 by default.
#   Ceiling: fastapi 0.115.6 pins starlette<0.42.
#
# streamlit — WINDOWS ONLY / LOCAL
#   - UNC SSRF in ComponentRequestHandler affects Windows hosts only.
#   - Weak hash in the caching layer requires local access.
#   The dashboard binds to localhost. See docs/RELEASE.md for the upgrade recommendation.
#
# pytest — DEVELOPMENT ONLY
#   /tmp/pytest-of-{user} local privilege issue. Not shipped and not part of the runtime.
# -------------------------------------------------------------------------------------
